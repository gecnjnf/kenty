# KENTY 2.0

KENTY — мессенджер и пространство для сообществ. Разработка KENTY 2.0 ведётся в отдельной ветке `kenty-2.0`; основная ветка и существующие данные не заменяются.

## Реализовано в ветке KENTY 2.0

- Регистрация и вход по никнейму и паролю через Supabase Auth.
- Профили: отображаемое имя, описание и аватар.
- Поиск пользователей, заявки в друзья и онлайн-статусы.
- Личные переписки и сообщения в реальном времени.
- Отправка фотографий в личные чаты.
- Редактирование и удаление собственных личных сообщений.
- Создание серверов и автоматический стартовый текстовый канал.
- Создание текстовых каналов и обмен сообщениями в реальном времени.
- Приглашения по ссылке и вступление по коду.
- Список участников сервера и статусы присутствия.
- Роли владельца, администратора, модератора и участника; изменение ролей и исключение участников с серверной проверкой прав.
- Тёмная и светлая темы, акцентные цвета, адаптация мобильного интерфейса.
- Установка веб-версии как PWA.

## Голосовые комнаты

Личные голосовые комнаты используют LiveKit SFU. Браузер получает короткоживущий токен через серверный маршрут `/api/token`. Сервер проверяет Supabase-сессию и право пользователя войти в комнату владельца или принятого друга. API Secret LiveKit остаётся только на сервере.

Для работы голосовой связи в соответствующей среде должны быть настроены:

- `LIVEKIT_URL` — WebSocket URL проекта LiveKit, начинается с `wss://`.
- `LIVEKIT_API_KEY` — API Key LiveKit.
- `LIVEKIT_API_SECRET` — API Secret LiveKit.
- `VITE_SUPABASE_URL` — URL проекта Supabase.
- `VITE_SUPABASE_ANON_KEY` — публичный ключ Supabase.

Не добавляйте API Secret или service-role ключи в клиентский код, GitHub или публичные переменные `VITE_*`.

**Важно:** серверные голосовые каналы пока не подключены к LiveKit. Текущая голосовая функция — отдельные личные комнаты. Для проверки аудио и видео нужны реальные устройства и корректные LiveKit credentials.

## Локальная разработка

Требуется Node.js 20+.

```bash
cd web
npm install
npm run build
```

Для локального запуска серверного маршрута `/api/token` используйте Vercel CLI и задайте перечисленные выше переменные окружения. Не коммитьте локальные env-файлы.
