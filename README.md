# KENTY

KENTY — мессенджер для общения с друзьями. Проект находится в активной разработке.

## Что уже реализовано

- Регистрация и вход по никнейму и паролю через Supabase Auth.
- Профили: отображаемое имя, описание и аватар.
- Поиск пользователей и заявки в друзья.
- Статусы пользователей онлайн.
- Личные переписки с обновлением сообщений в реальном времени.
- Отправка фотографий в личные чаты и просмотр изображений.
- Голосовые комнаты для владельца и его принятых друзей.
- Сообщества: создание серверов, вступление по приглашению, текстовые каналы и сообщения в реальном времени.
- Микрофон, камера, переключение камеры и демонстрация экрана в поддерживаемых браузерах.
- Тёмная и светлая темы, несколько цветов акцента.
- Установка веб-версии как PWA.

## Голосовые комнаты

Голосовые комнаты используют LiveKit SFU. Браузер получает короткоживущий токен через серверный маршрут `/api/token`. Сервер проверяет Supabase-сессию и право пользователя войти в комнату владельца или принятого друга. API Secret LiveKit остаётся только на сервере.

SDK LiveKit загружается динамически при подключении к голосовой комнате, чтобы не увеличивать начальную загрузку обычных чатов.

Для Production в Vercel нужны переменные:

- `LIVEKIT_URL` — WebSocket URL проекта LiveKit Cloud, начинается с `wss://`.
- `LIVEKIT_API_KEY` — API Key LiveKit.
- `LIVEKIT_API_SECRET` — API Secret LiveKit.
- `VITE_SUPABASE_URL` — URL проекта Supabase.
- `VITE_SUPABASE_ANON_KEY` — публичный ключ Supabase.

Не добавляйте API Secret или service-role ключи в клиентский код, GitHub или публичные переменные `VITE_*`.

## Текущие ограничения

Следующие функции ещё не входят в текущую версию или требуют отдельной реализации:

- Групповые личные переписки.
- Голосовые каналы внутри сообществ, управление ролями и расширенные права участников.
- Редактирование и удаление сообщений.
- Ответы и реакции на сообщения.
- Статусы прочтения и индикатор набора текста.
- Отправка произвольных документов и файлов.
- Полноценная доставка push-уведомлений.
- Восстановление пароля для аккаунтов без электронной почты или телефона.

Видеосвязь и демонстрация экрана зависят от поддержки браузера и операционной системы. Для подтверждения качества голосовой связи необходим тест между несколькими реальными устройствами и разными сетями.

## Стек

- React и Vite.
- Supabase Auth, Postgres, Realtime и Storage.
- LiveKit Client SDK и серверная генерация AccessToken.
- Capacitor для сборок Android/iOS.
- Electron для сборки Windows.

## Локальная разработка

Требуется Node.js 20+.

```bash
npm install
npm run build
```

Для локального запуска серверного маршрута `/api/token` используйте Vercel CLI из папки веб-приложения и задайте перечисленные выше переменные окружения. Не коммитьте локальные env-файлы.
